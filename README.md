# 005_cpp_learning：C++ 基础练习

27 个按编号排列的独立 C++ 示例，内容包括控制台输入输出、循环、字符串、结构体、引用、STL 容器、排序、字符分类和类型转换。每个 `.cpp` 都有自己的 `main()`，应逐个编译和运行；不能把全部文件一次性链接成一个程序。

仓库保留学习源码。原压缩包中的 `output/` 可执行文件、VS Code 本机配置及其他编译产物保留在本地，由 `.gitignore` 排除。

## 编译环境

需要 C++ 编译器及其标准库，没有 Python 依赖或第三方 C++ 库。代码没有使用 `bits/stdc++.h`，但部分字符串示例没有显式包含 `<string>`，可能依赖编译器标准库头文件的间接包含。

多数示例使用 C++11 的 `auto`、范围 `for`、无序容器和字符串转换功能；`009_jiehgouti.cpp` 还使用了 `.name = ...` 形式的指定成员初始化，其标准语法要求 **C++20**。下面的命令统一使用 `-std=c++20`，需要选择支持该标准的编译器。旧编译器可能不支持此选项或相应语法。

先在终端检查自己的编译器：

```powershell
g++ --version
```

若终端无法识别 `g++`，需要先配置已有编译器的路径。原有编辑器配置中写死的其他电脑路径不适用于克隆后的环境。

## 单独编译与运行

在项目根目录的 PowerShell 中，例如编译整数输入示例：

```powershell
New-Item -ItemType Directory -Path output -Force | Out-Null
g++ -std=c++20 -Wall -Wextra -Wpedantic .\001_cin.cpp -o .\output\001_cin.exe
.\output\001_cin.exe
```

程序等待输入时，输入一个整数并回车。例如输入 `5`，该示例输出 `输出是6`。中文显示取决于源码编码、编译器字符集和终端编码。

换成其他示例时，同时替换源文件和输出文件名。例如 `024_for.cpp` 不需要输入：

```powershell
g++ -std=c++20 -Wall -Wextra -Wpedantic .\024_for.cpp -o .\output\024_for.exe
.\output\024_for.exe
```

Linux 或 macOS 的终端可以使用相同的单文件编译方式，把输出改成对应平台的文件名和路径；上面的 PowerShell 目录命令不适用于其他 shell。不要使用 `g++ *.cpp -o ...`，因为多个 `main()` 会产生链接冲突。

## 当前需要注意的代码

- `020_sort.cpp` 先创建 `vector<int> m(9)`，有效下标是 0 到 8，但第一次循环就写入 `m[9]`。这是越界访问，会产生未定义行为，后面的 `push_back` 不能补救此前的写入。运行该示例前应先修正容量或循环边界；当前仓库保留原学习源码，不把它标记为已验证可运行。
- `008_sub.cpp` 最后调用 `s.substr(4)`，输入不足 4 个字符时会抛出异常；索引从 0 开始，索引 4 对应第五个字符。长度恰好为 4 时，后缀为空字符串。
- 接收数字的示例没有检查输入失败或整数范围，应提供有效且不会使自增溢出的输入。
- `019_bitset.cpp`、`009_jiehgouti.cpp` 等示例中有未使用的变量，部分循环还有有符号与无符号比较，开启警告后可能收到提示。字符分类函数的真值是非零，不应假定所有实现都输出数字 1。
